# Career Value

Assess 24–36 months against explicitly supplied goals. Link each path to assigned work, supported ownership, reusable capabilities, realistic next-role options, and prerequisites. State uncertainty around budget, adoption, autonomy, manager access, and progression.

- **Expanded:** adds relevant reusable capability or ownership that opens credible options.
- **Maintained:** deepens the existing direction with limited new options.
- **Narrowed:** shifts toward an unintended function/domain with limited transfer.
- **Unknown:** missing scope, autonomy, roadmap, or goals prevents assessment.

Describe risks of narrow operations or one-off implementation and possible mitigation. Do not assume title prestige or 0-to-1 work guarantees growth. Use the user's current preferences for ownership, function, stability, compensation, location, or domain; do not adopt preferences from examples.
