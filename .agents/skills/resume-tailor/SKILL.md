# Resume Tailor

Input: JD, analyzed requirements, fit results, one [Evidence document](../resume-intake/references/output-contract.md), and optionally the current resume. Output: prioritized changes with JD/Evidence references and input hashes; produce an actual text draft only when requested.

Promote supported experience that addresses Critical requirements. State what to emphasize, de-emphasize, reframe, or investigate and why. Without a current resume, use conditional recommendations rather than claiming an omission. Separate presentation problems from real gaps. Need evidence must not create a factual sentence.

Preserve roles, timeline, education, responsibility, and metric bounds. Do not turn targets into results or product responsibility into sole engineering implementation. Preliminary drafts disclose pending/self-reported limitations; application-ready wording requires specifically confirmed facts.

Keep drafts separate from the authoritative Evidence and original resume. Generated wording is not a new source. When a draft is requested, the agent can compose resume-review to check the actual generated text under its own review contract.
